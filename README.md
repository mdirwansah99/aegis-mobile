# 🛡️ AegisMobile Pro — Mobile Cyber Defense & Booster

**AegisMobile Pro** adalah aplikasi web progresif (PWA) pertahanan siber mudah alih, penggalak permainan, dan pembersih storan telefon pintar yang beroperasi 24/7 tanpa memerlukan sambungan komputer riba atau localhost.

---

## 🚀 Fitur Utama

1. **🛡️ Sekuriti & Anti-Scam:**
   - **Pengimbas Pautan Phishing:** Mengesan pautan berbahaya, domain berisiko tinggi (`.xyz`, `.top`, dll), dan cubaan memancing data perbankan palsu.
   - **Pengimbas Mesej SMS/WhatsApp:** Mengesan skrip penipuan popular (LHDN, MySejahtera, saman JPJ, bungkusan kurier, permintaan OTP/TAC).
   - **Pengimbas Fail APK SHA-256:** Mengira tandatangan kriptografi secara tempatan dan mengesan penyamaran sambungan berganda (contoh: `resit.pdf.apk`).

2. **📸 Pembersih Gambar Pendua (Media Deduplicator):**
   - Mengimbas gambar dalam galeri telefon menggunakan tandatangan digital kriptografi (Web Crypto).
   - Mengesan gambar serupa atau salinan bertindih dan mengira jumlah Megabait (MB) storan yang boleh dijimatkan.

3. **🧹 Pembersih Cache & Sampah Storan:**
   - Mengosongkan memori penimbal (*buffer*), storan sisa IndexedDB dan cache pelayar.

4. **🎮 Game Turbo & RAM Booster:**
   - **Kunci Skrin Permainan (Wake-Lock):** Menghalang skrin daripada terpadam atau malap semasa sesi bermain game.
   - **Pelepasan Tekanan Memori:** Mencetuskan kitaran *Garbage Collection (GC)* untuk mengurangkan lag.
   - **Penguji Kelancaran Skrin (Live FPS):** Mengukur kadar bingkai sesaat masa-nyata.

5. **📶 Penentudalam Isyarat & Rangkaian (Signal Booster):**
   - Telemetri talian masa-nyata (4G / 5G / WiFi, kependaman RTT ms, kelajuan downlink).
   - Penanda aras kependaman pelayan DNS global (Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9).
   - Protokol kalibrasi penyelarasan semula menara pemancar (*Cellular Baseband Re-handshake*).

## 📱 Cara Memasang di Telefon Pintar (Tanpa Laptop)

1. Buka pautan GitHub Pages di pelayar telefon anda (Google Chrome di Android atau Safari di iOS):
   ```
   https://mdirwansah99.github.io/aegis-mobile/
   ```
2. Tekan butang **"+ PASANG APP"** di bahagian atas, ATAU:
   - **Android (Chrome):** Tekan menu 3 titik di penjuru kanan atas $\rightarrow$ pilih **"Add to Home screen"** / **"Pasang Aplikasi"**.
   - **iOS (Safari):** Tekan butang **Share** (ikon petak dengan anak panah ke atas) $\rightarrow$ pilih **"Add to Home Screen"**.
3. Ikon **AegisMobile Pro** kini berada di skrin utama telefon anda dan boleh digunakan pada bila-bila masa, walaupun komputer riba dimatikan!
